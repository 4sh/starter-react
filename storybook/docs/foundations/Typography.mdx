## Fournir les fichiers de police

Les tokens **nomment** les familles, ils ne les **livrent** pas. `@4sh/ui-kit-react/styles.css`
ne contient aucun `@font-face`, et le kit n'appelle aucun CDN : les fichiers de police
appartiennent au projet, comme sa marque.

### Ce qui est garanti sans rien installer

Chaque `--fontfamily-*` généré se termine par une pile système. Une application qui
n'embarque aucune police s'affiche donc dans le sans-serif de l'OS : San Francisco,
Segoe UI, Roboto, et **jamais** dans le serif par défaut du navigateur :

```css
--fontfamily-base:       Inter, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--fontfamily-title:      "DM Sans", system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
--fontfamily-monospace:  "Roboto Mono", ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
--fontfamily-icon:       "Font Awesome 6 Free";
```

La première famille de chaque pile est celle du Design System ; les suivantes sont le
filet. La pile est ajoutée **au build** par `tokens.config.json` (clé `fontStacks` de la
collection `typography`) : le JSON de tokens, lui, garde le nom de famille nu, parce que
c'est ce que la variable Figma stocke. `--fontfamily-icon` n'a volontairement pas de
repli : une police d'icônes n'a pas de substitut lisible.

### Installer les vôtres, en trois gestes

**1. Poser les fichiers** dans `src/assets/fonts/`. Un format suffit : `.woff2`, supporté
partout, et une **variable font** couvre toute la plage de graisses en une ressource.

**2. Déclarer les `@font-face`** dans une feuille **globale** du projet :

```scss
// src/styles/vendors/_fonts.scss
@font-face {
  font-family: "Söhne";                          // le nom que le token ira chercher
  src: url("../../assets/fonts/soehne-variable.woff2") format("woff2");
  font-weight: 100 900;                          // variable font : toute la plage
  font-style: normal;
  font-display: swap;                            // texte visible pendant le chargement
}

@font-face {
  font-family: "Söhne";
  src: url("../../assets/fonts/soehne-variable-italic.woff2") format("woff2");
  font-weight: 100 900;
  font-style: italic;
  font-display: swap;
}
```

Le chemin est relatif à **ce** fichier : Vite le réécrit pour la feuille qui l'importe, et
empreinte la police au build. Écrivez-le en clair : une URL interpolée (`url("#{$dossier}/…")`)
n'est pas réécrite, et pointerait alors à côté une fois importée depuis un autre dossier.

**3. Pointer les tokens dessus**, dans la même feuille globale : en **gardant la queue de
pile**, sinon le serif revient au premier écran où la police n'a pas fini de charger :

```scss
:root {
  --fontfamily-base: "Söhne", system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
  --fontfamily-title: "Söhne Breit", system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
}
```

Rien d'autre à toucher : les composants lisent tous `var(--fontfamily-base)` ou
`var(--fontfamily-title)`, jamais un nom de police en dur.

### Où déclarer

Dans votre feuille globale, par exemple `src/styles/main.scss` (qui charge `_fonts.scss` par
`@use`), importée par le point d'entrée **après** `@4sh/ui-kit-react/styles.css` : les deux
écrivent sur `:root`, et c'est l'ordre des feuilles qui tranche.

```tsx
// src/main.tsx
import '@4sh/ui-kit-react/styles.css';
import './styles/main.scss';
```

Dans ce dépôt, la famille peut aussi se changer **à la source**, dans
`design-tokens/typography.json` puis `pnpm tokens:build`, plutôt que par surcharge.

### Pièges

<div className="sb-callout">

- **La surcharge vit dans la feuille globale.** Le CSS n'étant pas encapsulé, un `:root`
  écrit dans le `.scss` d'un composant s'appliquerait aussi, mais sa place dans la cascade
  dépendrait de l'ordre des imports et du découpage en chunks : la feuille globale, importée
  après `styles.css`, est le seul endroit où l'ordre est garanti.
- **Auto-héberger, pas de CDN.** Servir Google Fonts depuis ses serveurs transmet l'IP du
  visiteur à un tiers, c'est le point que la CNIL sanctionne, et casse tout build ou
  déploiement hors ligne.
- **Ne jamais laisser une famille seule.** `font-family: "Söhne"` sans queue de pile, c'est
  exactement le serif du navigateur qui revient dès que le fichier manque.
- **`font-display: swap`** évite l'écran de texte invisible pendant le téléchargement.
- **La police d'icônes est à part.** `--fontfamily-icon` ne fait que la nommer ; la feuille
  FontAwesome se charge séparément, par un import dans le point d'entrée :
  `import '@fortawesome/fontawesome-free/css/all.min.css'`, comme le fait ce Storybook.

</div>

# ui-editor

Éditeur de texte **riche**, bâti sur la coquille partagée
[`ui-field`](?path=/docs/components-ui-forms-ui-field--docs) (libellé, boîte, aide) en mode
multiligne : une barre d'outils configurable et une zone `contenteditable`.

**Aucun moteur d'édition tiers.** La mise en forme passe par l'API d'édition native du
navigateur, confinée dans `ui-editor-commands`, comme dans la version Angular : le kit reste
à ses deux dépendances. Un moteur (Tiptap, Lexical) aurait pesé dix fois plus, et aurait
écrit une autre forme de HTML que celle que les deux stacks partagent.

La valeur est une **chaîne HTML**. Elle est nettoyée par `sanitizeHtml`, le portage du
`DomSanitizer` d'Angular, avant tout affichage, et réduite à une courte liste de balises au
collage. Pour une saisie multiligne **sans** mise en forme, voir
[`ui-textarea`](?path=/docs/components-ui-forms-ui-textarea--docs).

## Barre d'outils

`tools` liste les outils rendus, dans l'ordre ; `separator` trace un séparateur. Outils :
`fontFamily`, `fontSize`, `bold`, `italic`, `underline`, `bulletList`, `orderedList`,
`indent`, `outdent`, `alignLeft`, `alignCenter`, `alignRight`, `alignJustify`, `textColor`,
`highlightColor`, `link`, `codeBlock`, `clearFormat`. Pas de niveau de bloc : l'éditeur ne
produit que des paragraphes.

### Police et taille

Les deux sont dans la barre par défaut. La police est fermée aux trois familles du système,
la taille à l'échelle typographique, et chacune s'écrit en **classe** adossée à un jeton
(`ui-editor-font-title`, `ui-editor-size-lg`) plutôt qu'en style : la valeur suit la marque
et le mode sombre, et reste la même dans les deux stacks.

### Alignement

Le navigateur aligne par `style="text-align: …"`. Le nettoyage laisse passer ces déclarations,
et seulement elles, avec le retrait : un paragraphe centré le reste quand la valeur revient du
serveur.

<Canvas of={EditorStories.TextAlign} />

### Couleurs

`textColor` et `highlightColor` ouvrent chacun un `ui-swatch-picker` ancré à leur bouton. La
couleur choisie s'écrit elle aussi en classe (`ui-editor-color-red-700`), sur la palette du
nuancier.

## Compteur et limite

`maxLength` et le compteur portent sur le **texte**, jamais sur le balisage. Une fois la
limite atteinte, les suppressions et la mise en forme restent possibles : seules les
insertions sont refusées.

<Canvas of={EditorStories.CharacterCount} />

## Formulaires

Contrôlé par `value` et `onValueChange`, non contrôlé par `defaultValue`, comme tous les
champs du kit.

```tsx
import { UiEditor } from '@4sh/ui-kit-react/ui-editor';

const [description, setDescription] = useState('');

<UiEditor
  label="Description"
  required
  value={description}
  onValueChange={setDescription}
  errorText="Ce champ est requis."
/>;
```

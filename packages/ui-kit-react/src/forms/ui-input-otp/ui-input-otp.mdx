# ui-input-otp

Saisie d'un code à usage unique, une case par caractère. Chaque case est un
`<input maxlength="1">` natif ; le groupe n'est qu'un `role="group"` qui les coordonne.

<Canvas of={OtpStories.Default} />

## API

<ArgTypes of={OtpStories} />

La valeur suit le contrat contrôlé du kit : `value` la fixe, `defaultValue` l'amorce,
`onValueChange` la rapporte. `onComplete` s'ajoute, et ne tire qu'une fois toutes les cases
remplies : c'est le moment où l'on valide, pas avant.

<Canvas of={OtpStories.Controlled} />

## Saisie

La frappe avance seule à la case suivante, `Retour arrière` efface et recule, et un code
**collé se répartit** sur les cases à partir de celle qui reçoit le collage. Le remplissage
automatique du navigateur, qui pousse le code entier dans une seule case, se répartit de la
même façon : les cases portent `autocomplete="one-time-code"`.

<Canvas of={OtpStories.Basic} />

`integerOnly` refuse tout ce qui n'est pas un chiffre, à la frappe comme au collage, et
demande le pavé numérique aux claviers virtuels. `mask` cache les caractères.

## Case sur mesure

`renderCell` remplace le contrôle. Le contexte donne le rang, la valeur, l'arrêt de
tabulation et les gestionnaires : tout ce qui n'est ni `index` ni `value` se branche tel
quel, et c'est ce qui garde le comportement du groupe.

⚠️ Le contrôle rendu doit rester un `<input>` : c'est ce que le groupe retrouve dans le DOM
pour faire glisser le focus de case en case.

<Canvas of={OtpStories.CustomCell} />

Rien n'empêche d'insérer autre chose entre les cases, un séparateur par exemple, du moment
qu'il est `aria-hidden`.

## Une case remplie seule

Rien n'oblige à remplir de gauche à droite : on peut cliquer la troisième case et y taper un
caractère. Les cases gardent alors leur **trou**, que la valeur jointe, elle, ne sait pas
porter (`'9'` ne dit pas dans quelle case il est). Ce sont donc les cases qui sont la source
du rendu, et elles ne se réalignent sur la valeur que quand celle-ci change sans venir
d'elles, c'est-à-dire quand un parent contrôlé impose autre chose.

# ui-file-upload-list

Une ligne de fichier : l'**unité qui se répète** dans la liste d'un envoi, à l'image du
composant Figma. [ui-file-upload](?path=/docs/components-ui-forms-ui-file-upload--docs) en
empile une par fichier. Présentationnelle : une vignette pour une image, une icône
sinon, le nom avec la taille ou l'état, et un bouton de retrait. Pendant l'envoi, un
`ui-spinner` prend la place de l'icône et une barre de progression apparaît.

Elle se livre dans le point d'entrée de `ui-file-upload`, dont elle rend le modèle :

```tsx
import { UiFileUploadList, type UiUploadFile } from '@4sh/ui-kit-react/ui-file-upload';
```

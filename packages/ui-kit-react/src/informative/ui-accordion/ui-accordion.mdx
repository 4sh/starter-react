# ui-accordion

Accordéon **headless** : un groupe de sections repliables. API de composition, un conteneur
`UiAccordion` qui porte l'état d'ouverture et les défauts du groupe, et des
`UiAccordionPanel` appariés par leur `value`.

## Modes

Mode **simple** par défaut : un seul panneau ouvert à la fois, et recliquer l'en-tête actif
le referme. Avec `multiple`, plusieurs panneaux restent ouverts et la valeur devient un
tableau.

<Canvas of={AccordionStories.Multiple} />

La valeur suit le contrat contrôlé du kit : `value` la fixe, `defaultValue` l'amorce,
`onValueChange` la rapporte. **`null` veut dire « rien d'ouvert »**, là où `undefined`
voudrait dire « non contrôlé », ce qui n'est pas la même chose. Pour observer les
transitions une par une, `onPanelOpen` et `onPanelClose` portent la valeur du panneau et
l'événement qui l'a provoquée.

<Canvas of={AccordionStories.Controlled} />

## En-tête

`header` accepte n'importe quel nœud : un titre texte suffit dans le cas courant, mais un
`UiTag`, une icône ou un compteur y tiennent tout autant. Là où le kit Angular a un slot
`uiAccordionHeader` en plus de son entrée texte, une seule prop couvre les deux cas.

<Canvas of={AccordionStories.RichHeader} />

## États

Un panneau `disabled` n'est pas repliable, et les flèches le sautent. Le trait et le
chevron se coupent par groupe ou par panneau.

<Canvas of={AccordionStories.DisabledPanel} />
<Canvas of={AccordionStories.Minimal} />

## Animation

Le pliage passe par le **système de motion** partagé : la technique `grid-template-rows`
sur un élément qui reste monté, donc `utils.motion-transition`. Coupez-la localement avec
`motion={false}`, globalement avec `data-motion="off"`, ou laissez la préférence système
`reduced-motion` la neutraliser. Voir **Foundations → Motion**.

## Exemples

```tsx
// Simple : un panneau ouvert à la fois.
<UiAccordion defaultValue="a">
  <UiAccordionPanel value="a" header="Section A">
    Contenu A…
  </UiAccordionPanel>
  <UiAccordionPanel value="b" header="Section B">
    Contenu B…
  </UiAccordionPanel>
</UiAccordion>;

// Multiple, en-tête riche, panneau désactivé.
<UiAccordion multiple defaultValue={['a']}>
  <UiAccordionPanel
    value="a"
    header={
      <>
        Facturation <UiTag label="À jour" level="success" size="small" />
      </>
    }
  >
    Contenu…
  </UiAccordionPanel>
  <UiAccordionPanel value="b" header="Archivé" disabled>
    Contenu…
  </UiAccordionPanel>
</UiAccordion>;

// Contrôlé, sans animation.
<UiAccordion value={open} onValueChange={setOpen} motion={false}>
  …
</UiAccordion>;
```

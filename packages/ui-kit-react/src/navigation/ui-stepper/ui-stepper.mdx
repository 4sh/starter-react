## La séquence se lit dans les enfants

L'avancement d'une étape se **déduit** de sa place : avant l'étape courante elle est franchie,
après elle est à venir. C'est ce qui distingue un stepper d'une bande d'onglets, et cela
suppose de connaître l'ordre.

Là où le kit Angular interroge sa projection, React a ses enfants sous la main comme une
**valeur** : la séquence est une fonction pure des `children`, sans état ni effet, et elle est
juste dès le premier rendu. La contrepartie est qu'un `UiStep` enveloppé dans un composant à
vous n'est pas vu ; déclarez-les directement sous `UiStepList` ou `UiStepper`.

## Deux dispositions

En **horizontal**, la bande est au-dessus et les panneaux en dessous.

En **vertical**, chaque `UiStepItem` porte son en-tête et son panneau, qui paraît juste
dessous, et le rail relie une étape à la suivante.

<Canvas of={StepperStories.Vertical} />

<div className="sb-callout">

**La sémantique ARIA suit la disposition.** En horizontal, c'est le motif onglets :
`role="tablist"`, `role="tab"` et `role="tabpanel"`. En vertical, le panneau est imbriqué sous
son propre en-tête, et un onglet qui contiendrait son panneau est de l'ARIA **invalide** : le
motif devient celui de l'accordéon, `aria-expanded` sur l'en-tête et `role="region"` sur le
panneau, le conteneur passant à `role="group"`. Dans les deux cas, l'étape courante porte
`aria-current="step"`, qui dit où l'on en est, ce qu'`aria-selected` ne dit pas.

</div>

## Mode linéaire

`linear` désactive les étapes situées **après** la courante : on ne saute pas en avant, mais on
revient toujours en arrière. On avance alors depuis le panneau, avec `useUiStepper`.

<Canvas of={StepperStories.Linear} />

```tsx
function Navigation() {
  const { next, prev, isFirst, isLast } = useUiStepper();

  return (
    <>
      <UiButton label="Précédent" level="low" disabled={isFirst} onClick={prev} />
      <UiButton label="Suivant" disabled={isLast} onClick={next} />
    </>
  );
}
```

⚠️ Un panneau qui n'est plus courant devient **inerte** : posez une navigation dans **chaque**
panneau, et non dans un seul, sinon elle cesse d'être atteignable dès la première étape
franchie.

## Indicateur d'avancement

Sans panneaux, la bande seule suffit. Aucun `aria-controls` n'est alors posé : un attribut qui
pointe sur un identifiant absent est pire qu'un attribut manquant.

<Canvas of={StepperStories.StepsOnly} />

## Marqueurs

`completedIcon` remplace le numéro des étapes franchies ; l'`icon` d'une étape gagne sur les
deux, quel que soit son état.

## État courant

La valeur suit le contrat contrôlé du kit : `value` la fixe, `defaultValue` l'amorce,
`onValueChange` la rapporte, et `onStepChange` ajoute l'événement d'origine.
